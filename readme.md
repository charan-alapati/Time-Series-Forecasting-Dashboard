# 📈 Time Series Forecasting Dashboard (Streamlit + LSTM)

## 🧠 Overview
This project provides an **interactive Streamlit dashboard** for forecasting future values in a time series using an **LSTM (Long Short-Term Memory)** model.

Users can upload their dataset, train the LSTM model directly from the web UI, and visualize predictions interactively.
